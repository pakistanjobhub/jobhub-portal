Privacy Policy

App: Islamic Home Decor Pins
Last updated: October 15, 2026

What this app does

Islamic Home Decor Pins is a personal content-publishing tool. It uses the Pinterest API to publish the app owner's own original images to the owner's own Pinterest boards, and to manage those boards. It is not offered to the public and has no other users.

Data we collect

The app accesses only the Pinterest account data needed for publishing: board lists and pin data belonging to the app owner's own Pinterest account, via the official Pinterest API with the owner's authorization. No data is collected from anyone else.

How data is used

Account data is used solely to create pins and manage boards as instructed by the owner. It is not sold, shared, or disclosed to any third party.

Data storage

API access tokens are stored securely and used only to communicate with the Pinterest API on the owner's behalf. No personal data is stored on external servers beyond what Pinterest itself holds.

Third parties

The app interacts only with the Pinterest API (api.pinterest.com). No other third-party services receive your data.

Contact

For questions about this policy, contact the app owner through the Pinterest account associated with this app.
